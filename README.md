# 📋 Job Application Tracker App

A simple and secure web-based Job Application Tracker built with **Python**, **Streamlit**, and **MySQL**. You can add, edit, delete, and filter jobs you've applied to — all from one place.

---

## 🔐 Features

- 🧑‍💻 **Login System** (For Personal Use)
- ➕ Add new job applications
- ✏️ Edit job entries
- ❌ Delete job records
- 🔍 Filter jobs by status
- 📥 Export job list to CSV
- 🐬 Data stored in secure MySQL database (Railway/MySQL etc.)
- 📱 Mobile-friendly UI (built with Streamlit)
